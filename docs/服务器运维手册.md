**2. 用法**：

```bash

```

**3. SSH 隧道（联调真后端）**：

```bash
# 前台（开发调试时手动跑）
~/.ssh/bin/paper3-ssh -N -L 9000:127.0.0.1:9000 \
  -o ServerAliveInterval=60 -o ExitOnForwardFailure=yes

# 后台（session 起手一次）
nohup ~/.ssh/bin/paper3-ssh -N -L 9000:127.0.0.1:9000 \
  -o ServerAliveInterval=60 -o ExitOnForwardFailure=yes \
  > /tmp/paper3-tunnel.log 2>&1 &
disown
lsof -nP -iTCP:9000 -sTCP:LISTEN    # 验证 Mac 9000 已 LISTEN
```

3. 服务器 `~/.ssh/config` 添加独立 Host 块（区分 fed-prompt 与 multimodal-project）
4. 服务器直接 `git pull` 不依赖本地会话

**注意**：multimodal-project 与 fed-prompt 的 deploy key 应**分别生成**（不同 key 对应不同 repo），不要共用——避免一个 repo 权限泄露影响另一个。

## 12.8 第一次接入 multimodal-project 的步骤

**首次（一次性）**：

1. **本地**：在 GitHub 创建空仓 `caiqiyue/multimodal-project`（**MUST NOT** 选 "Initialize with README"，保持空）
2. **本地 Windows**：
   ```bash
   cd E:\ai-learning\08-llm-application-development\multimodal-llm
   git init -b main
   git add -A
   git commit -m "chore: bootstrap multimodal-llm harness scaffolding"
   git remote add origin https://github.com/caiqiyue/multimodal-project.git
   git push -u origin main
   ```
3. **本地 Windows**：启动 ssh-agent + load GitHub key
   ```bash
   # Git Bash
   eval $(ssh-agent -s)
   ssh-add C:\Users\Administrator\.ssh\<github_key>
   ```
4. **本地 Windows**：带 forwarding 进入服务器
   ```bash
   ssh -A paper3-server
   ```
5. **服务器**：
   ```bash
   cd /mnt/public/caiqiyue_file
   git clone https://github.com/caiqiyue/multimodal-project.git
   cd multimodal-project
   git status  # 验证同步成功
   ```
6. **服务器**：建立 conda 环境 + 跑 baseline
   ```bash
   conda create -n multimodal_ai python=3.11 -y
   conda activate multimodal_ai
   pip install -U pip setuptools wheel
   pip install -r requirements.txt
   ./init.sh  # 跑基线验证
   ```

**日常（每次 session 开始）**：

1. 本地改代码
2. 本地 `git commit` + `git push`
3. `ssh -A paper3-server` 进入服务器
4. `cd /mnt/public/caiqiyue_file/multimodal-project && git pull --ff-only origin main`
5. 跑 `./init.sh` 确认 baseline 健康
6. 开新 feature 或继续 in_progress
